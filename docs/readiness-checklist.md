# Readiness Checklist — Antes de contactar al lead

Usar este checklist antes de enviar la demo.

## Repo

- [ ] El repo es privado.
- [ ] No hay `.vercel/output` trackeado.
- [ ] No hay `dist/` trackeado.
- [ ] No hay `.astro/` trackeado.
- [ ] No hay `node_modules/` trackeado.
- [ ] No hay ZIPs innecesarios.
- [ ] No hay screenshots o previews locales.
- [ ] `npm run build` pasa.

## Contenido

- [ ] No quedan referencias a Noir Barber Studio.
- [ ] El nombre del negocio aparece de forma consistente.
- [ ] Servicios principales están correctos.
- [ ] Horarios están correctos.
- [ ] Ubicación está correcta.
- [ ] Equipo está correcto.
- [ ] No hay Lorem ipsum.
- [ ] No hay textos genéricos de plantilla.

## Diseño

- [ ] Hero se ve premium en mobile.
- [ ] CTA principal aparece arriba del fold.
- [ ] Imágenes son placeholders aceptables.
- [ ] No se usaron fotos reales sin permiso.
- [ ] Paleta visual es coherente.
- [ ] No hay elementos que parezcan rotos o incompletos.

## Comercial

- [ ] La demo no promete reemplazar la agenda actual.
- [ ] Hay CTA a WhatsApp.
- [ ] Hay CTA a agenda externa.
- [ ] Hay sección de reseñas/reputación.
- [ ] Hay sección de retención.
- [ ] Hay argumento de conversión desde Instagram/TikTok/Google.
- [ ] Hay aviso de demo conceptual no oficial.

## Seguridad

- [ ] Tiene `noindex`.
- [ ] No se presenta como sitio oficial.
- [ ] Footer aclara que es demo conceptual.
- [ ] Deploy privado o preview controlada.
- [ ] Link probado en mobile.
